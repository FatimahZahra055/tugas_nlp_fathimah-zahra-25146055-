# E-commerce Product Reviews Sentiment Analysis

## Deskripsi
Notebook ini memuat dataset ulasan e-commerce berbahasa Indonesia dari Hugging Face:
[dipawidia/ecommerce-product-reviews-sentiment](https://huggingface.co/datasets/dipawidia/ecommerce-product-reviews-sentiment)

Kemudian dilakukan preprocessing teks (case folding, cleaning, tokenisasi, stopword removal, stemming) serta eksplorasi distribusi label sentimen.

## Fitur
- Load dataset e-commerce reviews (Bahasa Indonesia)
- Tampilkan informasi dataset: jumlah data, kolom, distribusi label sentimen
- Preprocessing teks: case folding, cleaning, tokenisasi, stopword removal, stemming
- Tampilkan 10 contoh teks sebelum dan sesudah preprocessing
- Jelaskan pengaruh preprocessing terhadap kualitas data

## Hasil
- Jumlah data: 11,606 ulasan
- Kolom: review, sentimen, translate
- Distribusi sentimen: 0 (negatif) = 5,803, 1 (positif) = 5,803
